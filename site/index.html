Snakecharmer

Configure Razer mice on Windows without Synapse: DPI, polling rate, button binds and lighting. Open source, copyleft, based on OpenRazer.

Features

DPI
Set and lock DPI. Tray presets are based on the mouse's supported range.
Polling rate
Up to 8000 Hz on mice that support it. Only rates the mouse supports are offered.
Button binds
Map buttons to keystrokes, including the DeathAdder Elite's two DPI buttons, which Windows doesn't receive on its own. On the DeathAdder V3, binds can be stored on the mouse, so they work when Snakecharmer isn't running, in games that block injected input, and on other PCs.
Lighting
Static, breathing, spectrum or off, set per zone. Effects run on the mouse, so nothing animates in the background.

Settings are applied at startup, and DPI is re-checked every 60 seconds. Use the tray menu for quick changes and the settings window for everything else.

Install

  1. Download snakecharmer.exe and save it anywhere. There's no installer.
  2. Run it. Windows SmartScreen may show "Windows protected your PC" because the exe isn't code-signed. Click More info, then Run anyway. Releases are built from the public source by GitHub Actions.
  3. Left-click the tray icon to open settings. Right-click it for DPI and lighting presets. Snakecharmer starts with Windows by default; turn this off with Start with Windows in the right-click menu.
  4. Optional: uninstall Synapse. First reset your buttons to default in Synapse, because some mice keep Synapse's binds in on-board memory. The Synapse removal guide covers what Synapse's uninstaller leaves behind.

Safety

  • Every command comes from OpenRazer's driver. Nothing is guessed or fuzzed.
  • It never touches firmware, the bootloader or update mode.
  • It never rebinds left or right click, so you can't lock yourself out of the mouse.
  • Quitting returns the mouse to its hardware mode. Stored binds reset with charmctl keymap reset.

Request a mouse

Open a request with your mouse's name. Someone else can write the code, and you can test it.

Add it yourself

  1. Find your mouse in the wishlist.
  2. Open an issue to claim it.
  3. Follow the cracking guide, or give your AI of choice the AI prompt.
  4. Open a pull request. It's usually one new file. See CONTRIBUTING for the checklist.
